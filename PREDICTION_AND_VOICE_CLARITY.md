# Prediction and voice clarity

Personal predictions forecasts the next recorded five-trial median reaction result in ms. A saved pending estimate (or latest historical result) now leads the page, with the trained-model estimate, recent-average comparator, status/window, and actual outcome/error when matched. Empty and error states do not fabricate a result. Technical discussion and full history are behind See more. A three-step workflow, loaded context count and cognitive-tab shortcut explain how to obtain the next comparison. Model training, coefficients, consent requirements, matching and account isolation are unchanged.

Voice retains duration and mean RMS only, with raw audio kept off the server. RMS can enter the personal recording-level reference and descriptive recent combined variation after enough earlier recordings. Duration is context. Neither feature is an input to the fixed reaction predictor. No speech-content, emotion, neurological disease or validated cognitive marker is derived. The voice page now states all of this directly; setup sensitivity is retained in its details.

The live browser session inspected during this change returned an expired-session API error. Existing stored forecasts had been verified in the previous live inspection, including a matched outcome, but private records could not be freshly revalidated in the expired session. The API client now refreshes once after an authentication rejection and retries that authorized request once; it shares concurrent refreshes, does not retry 403s or provider failures, and still asks for sign-in if refresh fails. Server authentication occurs before mutations. No tokens or private values are logged.
