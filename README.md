# NeuroTwin AI

Next.js App Router + React + Tailwind CSS 4. A landing page inspired by the supplied reference, with a custom SVG head that opens on hover/focus, decorative floating objects, and a brain link to `/home/`.

## Run

```sh
npm install
npm run dev
```

`npm run build` generates the static site in `out/`.

## Prototype scope

The home dashboard includes illustrative sample data until the first check-in. Sleep, movement, stress, and mood check-ins save to browser localStorage with consent. Recorded averages form a local baseline, and the history shows trends. Users can delete their records from Privacy & data.

The index is a transparent demo formula: up to 40 points from sleep/8 hours, 25 from activity/45 minutes, and 35 from inverse reported stress. It does not measure cognitive performance. No AI model, authentication, encrypted server storage, cognitive tests, voice analysis, or wearable integration is connected. The PDF’s full hybrid AI workflow remains a future backend implementation.

Design assets are original code-drawn SVGs; the reference artwork is not republished.
